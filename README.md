One-line museum placard for an ordinary office object, written as if it were an ancient artifact, for make.fun's "Office Artifacts: The One-Line Placard Contest" bounty. The entry program writes the placard to `/output/entry.txt`.

> Stapler, c. 1997. Pressed steel, one tired spring. Sacred binder of the Accounts tribe; pressed daily to seal pacts nobody read. Gift of a temp who left mid-sentence.

The joke: the humblest desk object recast as a sacred relic — a stapler worshipped by the Accounts tribe, its daily pressing a ritual that seals pacts nobody ever reads, donated by a temp who vanished mid-sentence. Deadpan curator voice, catalogue date, material, and donor all in one line.

## Run it

```sh
node main.ts
```

The program self-checks the placard before writing it: valid UTF-8, 1–180 characters, not only whitespace — the same gate the bounty applies.
